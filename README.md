# 土味情话大全

以土味情话内容为主题的小型网站。

本仓库保存经过脱敏的源码快照，属于开发原型。

## 功能

- 语录内容展示。
- 随机语句按钮与静态页面交互。

## 运行

用浏览器打开 `index.html`，或运行 `python3 -m http.server 8000` 预览。

## 当前范围

已有静态HTML原型。
